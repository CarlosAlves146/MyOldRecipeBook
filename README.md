# 🍳 MyOldRecipeBook

> 📚 Projeto desenvolvido para aprimorar conhecimentos em **.NET**, **C#**, arquitetura de software, testes automatizados, DevOps e integração com Inteligência Artificial.

---

## 🚀 Sobre o projeto

O **MyOldRecipeBook** é um projeto de estudo e desenvolvimento de uma **API de Livro de Receitas**, criado com o objetivo de colocar em prática conceitos e tecnologias utilizados no desenvolvimento de aplicações modernas com **.NET**.

A ideia principal é permitir que o usuário possa:

* 👤 Criar e gerenciar sua conta;
* 🔐 Realizar autenticação de forma segura;
* 🍝 Cadastrar suas próprias receitas;
* 🔎 Pesquisar e filtrar receitas;
* 🥕 Encontrar receitas com base nos ingredientes disponíveis;
* 🤖 Utilizar **Inteligência Artificial** para receber sugestões de receitas;
* 📱 Consumir as funcionalidades através de uma API.

O projeto está sendo desenvolvido de forma incremental, permitindo aplicar novos conhecimentos conforme o desenvolvimento avança.

### 🤖 Inteligência Artificial

Uma das funcionalidades planejadas para o projeto é a integração com Inteligência Artificial.

A ideia é permitir que o sistema analise os ingredientes disponíveis e sugira receitas que possam ser preparadas com eles.

**Exemplo:**

```text
🥕 Ingredientes disponíveis:

- Frango
- Tomate
- Cebola
- Arroz

🤖 IA:

"Você pode preparar um arroz de frango com tomate e cebola."
```

Essa funcionalidade tem como objetivo explorar, na prática, possibilidades de integração entre aplicações **.NET** e serviços de IA.
